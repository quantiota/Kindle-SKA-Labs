# Kindle SKA Labs

Companion files for the book: the laboratory scripts and datasets used in Chapter 10 of **Foundations of Structured Knowledge
Accumulation, Part I: An Autonomous Framework for Layer-Wise Entropy Reduction in Neural
Learning** by Dr. Bouarfa Mahi.

| File | Used in |
|---|---|
| `labs/2503.13942v1_per_class.py` | Lab 4: the reference script with per-class measurements |
| `labs/dataset/mnist_subset_100_per_class.pt` | all labs: 1,000 images, 100 of each digit 0–9 |
| `labs/dataset/mnist_subset_1_per_class.pt` | Lab 4, Run 1: one of each digit |
| `labs/dataset/mnist_subset_10_for_class_0.pt` | Lab 4, Run 2: ten images of digit 0 |
| `labs/dataset/mnist_subset_4x0_3x1_3x8.pt` | Lab 4, Run 3: four 0s, three 1s, three 8s |

The reference implementation and the result files are in
[quantiota/Arxiv](https://github.com/quantiota/Arxiv); the SKA Explorer applications of Lab 6 are at
[huggingface.co/quant-iota](https://huggingface.co/quant-iota).
